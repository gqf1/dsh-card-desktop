# dsh-desk-all — 卡片桌面全家桶

把 **卡片桌面（代码工作台）** 和 **音乐播放器** 打成一个包，装一次两个都有，装完还能**各自单独开关**。

跟 `@linxin666/dsh-web-all` 是同一个思路：一个聚合包挂多个插件行，你在插件管理器里按行开关。

---

## 里面是什么

| 插件 | 用途 | 在 DSH 里的样子 |
|---|---|---|
| `dsh-card-desktop` | 卡片桌面 / 代码工作台 | 侧栏出现「卡片桌面」入口，点进去是全屏工作台：Explorer、Verilog 编辑器、Git 面板、终端、AI 对话 |
| `dsh-music-hub` | 音乐播放器 | 所有会话的输入框上方多一条播放条；卡片桌面里多一张「音乐」卡片 |

**两个插件互不依赖。** 关掉任意一个，另一个照常工作。

---

## 安装

### 桌面客户端（推荐）

1. 打开 DSH →「设置」→「插件管理器」
2. 点 **Add plugin**
3. 填：

   ```
   github:gqf1/dsh-card-desktop#bundle
   ```

   > `#bundle` 必须带上——它指向主仓库里的 `bundle/` 子目录，也就是本包。

4. 提交，等它装完
5. **完全退出 DSH 再重新打开**

> **退出 ≠ 关窗口。** 点右上角 `×` 只是收进托盘。要从**托盘图标右键 → 退出**，再重新启动。

### 命令行 / 浏览器版

```bash
dsh plugin --profile web add github:gqf1/dsh-card-desktop#bundle
```

装完同样要重启 DSH。

### 装完怎么确认

进插件管理器，列表里应该同时出现：

- `dsh-desk-all` —— 聚合壳本身
- `card-desktop` —— 卡片桌面
- `music-hub` —— 音乐

三者都在，就是装齐了。

---

## 开关单个插件

进「插件管理器」，找对应的行，点开关，然后**重启 DSH**。

| 想要的效果 | 操作 |
|---|---|
| 只要代码工作台，不要音乐 | 关掉 `music-hub` |
| 只要音乐播放条，不要卡片桌面 | 关掉 `card-desktop` |
| 全部暂停但保留配置 | 关掉 `dsh-desk-all`（子插件跟着不加载） |

> 关掉 `music-hub` 后，卡片桌面里的「音乐」卡片**照样能点**，进去是空面板——这是有意的降级，**不会报错，也不影响代码工作台**。

---

## 卸载

插件管理器里卸载 `dsh-desk-all`，两个子插件会一起被移除。

如果还想留其中一个，先单独装那一个（见各自 README），再卸本包。

---

## 版本对应

| 本包 | `dsh-card-desktop` | `dsh-music-hub` | 要求 DSH |
|---|---|---|---|
| 0.6.0 | ≥ 0.6.0 | ≥ 0.1.0 | ≥ 0.2.2-rc.1 |

两个子插件用 `github:` 依赖声明，装的时候会拉各自仓库的最新版。

## 出问题时

**装完什么都没有**
→ 90% 是没真退出。托盘右键退出，再启动。

**只有卡片桌面，没有音乐播放条**
→ 插件管理器里看 `music-hub` 那一行在不在、是不是被关了。

**插件面板整个消失（所有插件都没了）**
→ 多半是行 id 重复：同时装了本聚合包和单独装的 `dsh-card-desktop` / `dsh-music-hub`。
两条路线只能走一条。先卸掉单独装的那份，再重启。

**卡片桌面里的「音乐」是空白页**
→ `music-hub` 没装或被关了。装上或打开它，重启生效。
